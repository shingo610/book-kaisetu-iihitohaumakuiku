Build Credit
貸しをつくる６つの行動
①
小さな親切を積み重ねる
資料を整える、一言フォローするなど日常的な気遣い。人は「大きな1回」より「小さな積み重ね」で信頼を判断する。
②
役立つ情報を共有する
相手の成果を上げる情報・事例・やり方を伝える。知識はコストゼロで渡せるのに成果を大きく変える。
③
人と人をつなぐ
相性が良さそうな人同士を紹介する。人の価値は「誰とつながっているか」で大きく変わる。
④
相手の成功を喜ぶ
相手の成果や成長を素直に褒める。人は「自分を認めてくれる人」に強い好意を持つ。
⑤
困りごとを先回りする
相手が言う前に「これ必要そう」と動く。一番の価値は「相手の手間を減らすこと」。
⑥
記憶に残る体験をつくる
一緒に良い経験・成功体験・楽しい時間をつくる。人は事実より「感情」で記憶する。

Practical Skills

⚡

時間は全員にとって最も価値の高い資源。
「仕事しやすい人」と思われ、信頼が一気に上がり、仕事が集まってくる。
NEW CONCEPT
即レスは「時間のプレゼント」
素早い返信は、単なるマナーではない。
相手が「待つ」という時間コストをゼロにする、
最もコストパフォーマンスの高いギフトだ。
相手は返信を待つ間、頭の片隅にそのタスクを抱え続ける。
即レスはその「精神的な在庫」を解放し、
相手の集中力と安心感を一度に取り戻させる。
💡 目安：メール・チャットは受け取った瞬間から1時間以内。
すぐ答えられない場合でも「確認します」の一言を先に送る。
✓ 仕事しやすい人と思われる ✓ 信頼が上がる ✓ 仕事が集まってくる
👤
名前を呼ぶ UPDATED
会話の中で相手の名前を使う。
人は「自分を認識してくれる人」に安心感を持つ。
距離が縮まり、印象に残り、コミュニケーションが円滑になる。
🧠 心理学的根拠
カクテルパーティー効果
騒がしいパーティー会場でも、自分の名前が呼ばれた瞬間だけはっきり聞こえる——これがカクテルパーティー効果だ。人の脳は無意識のうちに「自分の名前」を特別な信号として処理する。名前を呼ぶことは、相手の注意を瞬時にこちらへ向け、「あなただけに話しかけている」というメッセージを送ることに等しい。
😊 名前を呼ばれると嬉しいシチュエーション
大勢の場で発言を拾われたとき
「〇〇さんが先ほど言っていた点、まさにそれです」——雑多な会議の中で自分の意見が名前付きで拾われると、存在を認められた実感が湧く。
メールや連絡の書き出しで呼ばれたとき
「〇〇さん、お疲れ様です」——たった一言でも、定型文ではなく「自分宛て」に書かれた文章だとわかり、読む前から前向きな気持ちになれる。
褒めるときに名前を添えられたとき
「〇〇さんのあの対応、本当に助かりました」——名前のない「ありがとう」より、名前付きの感謝は何倍も記憶に残り、自己肯定感を高める。
✓ 距離が縮まる ✓ 印象に残る ✓ 会話が円滑に
🙏
感謝は具体的に伝える UPDATED
何に対して感謝かを明確に言う。
「ちゃんと見てくれている」と感じさせる。
相手のモチベーションが上がり、協力を得やすくなり、信頼関係が深まる。
💬 具体的な感謝の例文 3パターン
「昨日の会議で、私が詰まっていたところをさりげなくフォローしてくださったおかげで、スムーズに進めることができました。本当に助かりました。」
「資料に図を追加してくれたこと、すごく分かりやすくなりましたし、先方にも好評でした。あの一工夫がなかったら、うまく伝わっていなかったと思います。ありがとうございます。」
「締め切り直前に確認を入れてくれていましたよね。あのタイミングで声をかけてもらえたから、ミスを防げました。気にかけてくれてありがとうございます。」
✓ モチベーションが上がる ✓ 協力を得やすい ✓ 信頼が深まる

期待の言葉をかける UPDATED
相手の良い点を言葉にして伝える。
人は言われたイメージに近づこうと行動する。
相手の成長を引き出し、チームの成果が上がり、リーダーとして評価される。
🧠 心理学的根拠
ラベリング効果
人は他者から貼られた「ラベル（レッテル）」に沿って行動しようとする心理がある。「あなたは丁寧な人だ」と言われた人は、無意識にその像に近づこうと行動を変える。批判や指示よりも、あるべき姿を言葉で伝えるほうが、相手の内発的な動機を引き出しやすい。ラベルは「評価」ではなく「期待」として渡すのがポイント。
💼 会社で使えるラベリングの例 3パターン
ミスが続いている後輩に対して
「〇〇さんって、一度気づいたことは絶対繰り返さないタイプだよね」——ミスを責めるのではなく、成長できる人というラベルを先に貼る。本人が「そういう人でいよう」と行動を変えやすくなる。
消極的なメンバーに発言を促したいとき
「〇〇さんの視点って現場目線で鋭いから、ぜひ意見を聞かせてほしい」——発言を「義務」としてではなく、その人の強みとして位置づけることで、自然と口を開きやすくなる。
新しい役割を任せたいとき
「〇〇さんって周りをよく見てる人だと思うから、このプロジェクトのまとめ役をお願いしたい」——役割と人物像をセットで伝えることで、任された側がその役割にふさわしい行動を自ら選ぶようになる。
✓ 成長を引き出せる ✓ チームの成果UP ✓ リーダーと評価される

失敗を責めない UPDATED
ミスより改善にフォーカスする。
責められると人は挑戦をやめる。
チャレンジする人が増え、学習スピードが上がり、成長するチームになる。
🧠 心理学的根拠
心理的安全性（Psychological Safety）
Googleが数千チームを調査した結果、最も成果を上げるチームに共通していたのが「心理的安全性」だった。これは「失敗しても責められない」という安心感のこと。この安心感があるとき、人はリスクを取り、意見を言い、新しいことに挑戦する。逆に、一度でも責められると脳は「挑戦＝危険」と学習し、無難な行動しか取らなくなる。
💼 会社で使える「責めない」言い換え例 3パターン
ミスが起きたとき
「なぜやったの？」→「次はどうすればうまくいきそう？」——原因追及より改善思考へ切り替える一言。本人が自分で解決策を考えるので、再発防止の効果も高い。
報告が遅れたとき
「なんで早く言わなかったの」→「早めに言いにくい雰囲気があった？」——責任をチームの環境問題として捉え直す。次から相談しやすくなり、問題の早期発見につながる。
チャレンジが失敗したとき
「だから言ったでしょ」→「やってみたこと自体は良かったよ。何が学べた？」——失敗を「学習コスト」として肯定する。次の挑戦への心理的ハードルを下げ、行動量が増える。
✓ 挑戦が増える ✓ 学習スピードUP ✓ 成長チームになる

🧠 心理学的根拠
反応バイアスと沈黙のコスト
人は「この意見を言ったら変に思われないか」という評価懸念を感じると、発言を抑制する。これを「沈黙のコスト」という。一人が黙ると周囲も黙り、組織全体が表面上は問題なく見えていても内側では不満やリスクが蓄積していく。最初の一言を否定しないことが、チーム全体の口を開かせる最も簡単なトリガーになる。
💼 会社で使える「本音を引き出す」言い方 3パターン
会議で意見が出ないとき
「何かある人？」→「正直なところどう思う？ どんな意見でもOK」——オープンな問いかけに「正直」「どんな意見でも」を添えるだけで、発言の心理コストが下がる。
否定的な意見が出たとき
「でもそれは難しいよね」→「なるほど、そういう見方もあるね。もう少し聞かせて」——まず受け取る姿勢を見せることで、その後も意見が出続ける場の雰囲気をつくれる。
1on1や雑談の場で
「最近どう？」→「最近、正直しんどいことや気になってることある？」——具体的な問いを添えることで、表面的な「大丈夫です」から一段深い本音へ誘導できる。
✓ アイデアが増える ✓ 問題が早く見つかる ✓ 強いチームになる
